# Reel con Claude

Skill gratis de Claude Code para editar tus videos para redes: corta pausas y tomas repetidas, pone subtítulos palabra por palabra y anima títulos, tarjetas, logos, fotos y clips en el segundo exacto en que hablas. Antes de editar te pide tu objetivo, tu marca y un video de referencia.

## ⬇ Descargar

**[reel-con-claude.zip](https://github.com/alemorenovj/reel-con-claude/releases/latest/download/reel-con-claude.zip)**

## Instalar

1. Instala lo necesario:
   - **Mac:** `brew install node ffmpeg whisper-cpp` (si no tienes brew: https://brew.sh)
   - **Windows:** `winget install OpenJS.NodeJS Gyan.FFmpeg Python.Python.3.12` (whisper te lo instala Claude)
2. Descomprime el zip y mueve la carpeta `reel-con-claude` a `~/.claude/skills/` (Windows: `C:\Users\TU-USUARIO\.claude\skills\`).
3. Cierra y vuelve a abrir Claude Code.
